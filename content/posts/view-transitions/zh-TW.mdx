過去要讓切換頁面時有淡入淡出或滑動效果，常見做法是用 JavaScript 控制內容切換，再搭配 CSS 動畫或動畫函式庫。View Transitions API 讓瀏覽器協助銜接切換前後的畫面；除了同一頁內的內容更新，符合條件的不同 HTML 頁面之間也能轉場，不必為了動畫把網站改成 SPA。

## 漸進增強比動畫更重要

最基本的原則是：沒有轉場時，導覽仍然要正常運作。動畫應該是體驗增強，而不是功能依賴。

```css
::view-transition-old(root) {
  animation: fade-out 160ms ease;
}

::view-transition-new(root) {
  animation: fade-in 220ms ease;
}
```

## 適合的使用情境

- 文章列表進入文章內容
- 圖片縮圖放大成詳情頁主視覺
- 同一資訊在不同版面間移動
